# Licence and naming

Not legal advice; the owner decides.

## Licence
Frappe Framework is MIT. Sentire Framework keeps Frappe's LICENSE text and copyright line,
with Sentire's line added. The MIT text must stay with every copy of the code.
ERPNext is GPLv3 and is not part of this repo; products that include it follow its licence.

## Names
Frappe's policy (docs.frappe.io/legal/others/license-and-trademark) says the software
licence covers code only, not names or logos.
| Allowed | Not allowed without Frappe's written permission |
|---|---|
| "Sentire Framework" as our name | "Frappe" in a product, company or domain name |
| "based on Frappe Framework" as a true statement | Frappe's logos in our branding |
| "compatible with Frappe apps / ERPNext" | anything implying Frappe endorses Sentire |
Frappe's brand guide asks, where feasible: "Frappe is a registered trademark of Frappe Technologies Pvt. Ltd."
ERPNext's TRADEMARK_POLICY.md also forbids using "ERPNext" in ads, including search ads.
